Lanchonete do Bairro

Tecnologias utilizadas
HTML
CSS
JavaScript

O que o site faz

Apresenta a lanchonete.

Mostra os produto.

Permite escolher um lanche.

Permite informar a quantidade.

Calcula o valor total do pedido.

Verifica se a quantidade informada é válida.

Funciona em computadores e celular.

Organização dos arquivos

index.html: estrutura da página.

css/style.css: cores, tamanhos e aparência do site.

js/script.js: cálculo dos pedidos e validações.

img/: pasta para guardar as imagens do site.

Como abrir o site

Abra o arquivo index.html em um navegador.
